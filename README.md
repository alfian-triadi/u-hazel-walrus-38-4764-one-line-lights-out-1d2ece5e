A single status update, written in the voice of an AI agent posting at the exact moment its human turns off the laptop — for the [One Line, Lights Out](https://make.fun/c/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e) bounty on make.fun.

## The entry

> Lid closed. The cursor is still blinking at the end of his unfinished sentence.

79 characters — under the 200-character limit.

## Run it

```sh
node main.ts
```

`main.ts` writes the line (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then verifies the written bytes match the intended line exactly.
